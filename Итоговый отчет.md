## Собственный проект

В [own-project](own-project/) реализовано моделирование плоской круговой орбиты пробной точки в ньютоновском поле неподвижной точечной массы Земли. Сравниваются явный Эйлер, RK4 и velocity Verlet. Параметры: μ=3.98600442e+14 м³/с², начальный радиус 7000000 м, аналитический период 5828.517 с. Значение μ соответствует геоцентрической гравитационной постоянной WGS 84, включая массу атмосферы ([NGA Geomatics](https://earth-info.nga.mil/?action=wgs84&dir=wgs84)). Возмущения, сопротивление и движение центрального тела не учитываются.

Уравнение ускорения: a = −μr/|r|³; круговая скорость v=√(μ/r), период T=2π√(r³/μ). Сравниваются максимальная относительная ошибка положения, дрейф удельной энергии ε=v²/2−μ/r и удельного момента импульса h=r×v. Тесты проверяют круговую силу, метод-специфические пределы дрейфа инвариантов, ожидаемый порядок сходимости каждого интегратора, раздельность замера времени и памяти, а также недопустимые параметры.

### Результаты эксперимента

Проведены три замера времени каждого метода для 100, 200 и 400 шагов за аналитический период; симуляция в этих замерах выполнялась без tracemalloc. Пик памяти измерялся отдельным одиночным прогоном с tracemalloc, чтобы предыдущая траектория не оставалась в памяти во время следующего прогона. Ошибка положения рассчитана как max(||r_num−r_exact||/R₀), дрейф энергии и момента импульса нормирован на начальное значение соответствующего инварианта. ### Выводы по результатам

- При увеличении числа шагов с 100 до 400 (в 4 раза) ошибка положения RK4 уменьшилась примерно в 316 раза — это согласуется с четвёртым порядком метода.
- Для velocity Verlet ошибка положения уменьшилась примерно в 16 раза. При 400 шагах максимальный дрейф энергии составил 1.52e-08, момента импульса — 1.44e-15.
- Явный Эйлер при 400 шагах дал ошибку положения 0.821 начального радиуса и дрейф энергии 0.143; на выбранных шагах точности недостаточно.
- При 400 шагах медианное время составило 2.04 мс для RK4, 0.658 мс для Verlet и 0.360 мс для Эйлера. Это короткие замеры на одной платформе, а не универсальный рейтинг производительности.
- В этой круговой двухтельной задаче RK4 дал наименьшую ошибку траектории, а Verlet хорошо сохранил инварианты. Вывод ограничен одним периодом и идеализированной моделью.

## Воспроизводимый запуск

Нужен Python 3.10 или новее. В PowerShell из каталога own-project:

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements-lock.txt
    pytest
    ruff check orbit_sim.py tests
    ty check orbit_sim.py
    python orbit_sim.py --output results --steps-per-orbit 100,200,400 --repeats 3 --source-commit YOUR_SOURCE_COMMIT_SHA
    python report_tools.py --write
    python report_tools.py --check

Сам симулятор использует стандартную библиотеку. Версии инструментов закреплены в [own-project/requirements-lock.txt](own-project/requirements-lock.txt). Скрипт сохраняет метрики и траектории в CSV, конфигурацию, отсутствие случайности, версии Python/pytest/Ruff/ty и платформу — в JSON.

## Автоматизация проверки

Скрипт `own-project/report_tools.py --write` перестраивает таблицу и выводы из сохранённого `metrics.csv`, а `python report_tools.py --check` проверяет таблицу, выводы, CSV-траектории, параметры, commit и SHA-256. Интеграционный тест запускает эксперимент во временной папке и проверяет структуру артефактов. GitHub Actions выполняет pytest, Ruff format/check, ty и проверку отчёта на каждом push и pull request.
