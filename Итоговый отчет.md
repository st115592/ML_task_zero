## Научный аудит

Основные формулы взаимного ньютоновского притяжения, скорости круговой орбиты, vis-viva и идеальных переходов соответствуют модели. Замечания:

- G=1 задано без определения системы единиц; результаты нельзя считать SI.
- При оценке площадной скорости смешаны относительный радиус-вектор и абсолютная скорость.
- README обещает демонстрацию всех трёх законов Кеплера, но третий закон не проверяется вычислительно.
- Импульсы применяются внутри callback анимации с временным и абсолютным радиальным допуском.
- Радиус от центра в графике подписан как высота над поверхностью.

Это учебная визуализация идеальной динамики, не расчёт реальной миссии. Полный статический аудит и источники — в [02_audit.md](02_audit.md).

## Собственный проект

В [own-project](own-project/) реализовано моделирование плоской круговой орбиты пробной точки в ньютоновском поле неподвижной точечной массы Земли. Сравниваются явный Эйлер, RK4 и velocity Verlet. Параметры: μ=3.98600442e+14 м³/с², начальный радиус 7000000 м, аналитический период 5828.517 с. Возмущения, сопротивление и движение центрального тела не учитываются.

Уравнение ускорения: a = −μr/|r|³; круговая скорость v=√(μ/r), период T=2π√(r³/μ). Сравниваются максимальная относительная ошибка положения, дрейф удельной энергии ε=v²/2−μ/r и удельного момента импульса h=r×v. Тесты проверяют круговую силу, физические инварианты, сходимость RK4 и недопустимые параметры.

## Воспроизводимый запуск

Нужен Python 3.10 или новее. В PowerShell из каталога own-project:

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements-lock.txt
    pytest
    ruff check orbit_sim.py tests
    ty check orbit_sim.py
    python orbit_sim.py --output results --steps-per-orbit 100,200,400 --repeats 3

Сам симулятор использует стандартную библиотеку. Версии инструментов закреплены в [own-project/requirements-lock.txt](own-project/requirements-lock.txt). Скрипт сохраняет метрики и траектории в CSV, конфигурацию, отсутствие случайности, версии Python/pytest/Ruff/ty и платформу — в JSON.
