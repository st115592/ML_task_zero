# Шаг 1. Структура проекта OrbitalMechanics

## Объект и границы исследования

- Источник: [AakaashfromIndia/OrbitalMechanics](https://github.com/AakaashfromIndia/OrbitalMechanics).
- Локальная папка клона: `ML/`.
- На момент просмотра клон содержит README и три Python-скрипта в корне.
- Этот этап был только структурным: код не изменялся, формулы оценены отдельно в [аудите](02_audit.md).

## 1. Файлы и назначение

| Файл | Назначение | Основные части |
| --- | --- | --- |
| `Two body system.py` | Модель двух тел, вращающихся вокруг общего центра масс | `two_body_dynamics`, `setup_elliptical_orbit`, энергия, момент импульса, анимация и графики |
| `Hohmann Transfer.py` | Переход аппарата между двумя круговыми орбитами | `spacecraft_dynamics`, `setup_hohmann_transfer`, расчёт элементов орбиты, слайдеры и графики |
| `Bielliptic Maneuver.py` | Трёхимпульсный биэллиптический переход | `spacecraft_dynamics`, `setup_bielliptic_transfer`, слайдеры и графики |
| `README.md` | Описание, зависимости и запуск | Некоторые имена файлов и каталога в командах не совпадают с клоном |

Структура плоская. Общего пакета, `src/`, конфигураций, CI, файлов данных и `tests/` нет. Каждый скрипт объединяет расчёт модели и код пользовательского интерфейса.

## 2. Зависимости

Исходный код импортирует:

- **NumPy** — вычисления;
- **SciPy** (`scipy.integrate.solve_ivp`) — численное интегрирование;
- **Matplotlib** — графики, анимация, слайдеры и кнопки.

README предлагает `pip install numpy scipy matplotlib`. Версии пакетов и минимальная версия Python не заданы; `requirements.txt` и `pyproject.toml` отсутствуют.

## 3. Точки входа и запуск

Все три файла — самостоятельные скрипты. Код верхнего уровня создаёт графики и анимацию, а затем вызывает `plt.show()`. Блока `if __name__ == "__main__":` нет, поэтому импорт модуля также запустил бы построение GUI.

Из папки клона запускать так:

```powershell
python "Two body system.py"
python "Hohmann Transfer.py"
python "Bielliptic Maneuver.py"
```

В README указаны другие имена с дефисами (`Two-body-system.py`, `Hohmann-Transfer.py`, `Bielliptic-Maneuver.py`) и имя каталога `orbital-mechanics-simulations`, которого в клоне нет. Команды из README в текущем виде не соответствуют фактической структуре.

Запуск предполагает GUI-бэкенд Matplotlib. CLI-режим и сохранение графиков в файл не описаны.

## 4. Тестирование и воспроизводимость

Автоматических тестов и команды для тестирования не обнаружено. Исходные параметры заданы внутри скриптов, часть доступна через слайдеры. Чтобы воспроизвести численный запуск, потребовалось бы дополнительно зафиксировать версии Python и библиотек, backend Matplotlib, значения параметров и скорость анимации.
