# ML в механике — учебное задание 0

Репозиторий содержит исследование учебного проекта по орбитальной механике, статический научный аудит и собственный проект сравнения численных интеграторов.

- [Итоговый отчёт](Итоговый%20отчет.md) — структура, аудит, собственный проект, результаты и команды.
- [01_structure.md](01_structure.md) — структура, зависимости, точки входа и запуск upstream-проекта.
- [02_audit.md](02_audit.md) — научный аудит и источники.
- [AGENTS.md](AGENTS.md) — правила работы с кодом.
- [own-project](own-project/) — исходник, тесты, lock-файл и результаты эксперимента.

Проверки собственного проекта: 14 тестов pytest, форматирование Ruff, линтер Ruff и ty запускаются в GitHub Actions при push и pull request. Скрипт `own-project/report_tools.py` сверяет итоговую таблицу и выводы отчёта с CSV, JSON, контрольной суммой и commit исходника.
