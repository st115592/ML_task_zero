# Журнал работы с агентом — «ML в механике»

## Шаг 1. Поиск и клонирование учебного проекта

**Запрос:** найти небольшой открытый проект по физике/ML и клонировать его в папку `ML`.

**Результат:** выбран [AakaashfromIndia/OrbitalMechanics](https://github.com/AakaashfromIndia/OrbitalMechanics). В нём три симуляции: задача двух тел, переход Хомана и биэллиптический переход. Пример оформления работы: [st117157/ml-mechanics-hw2](https://github.com/st117157/ml-mechanics-hw2).

## Шаг 2. Исследование структуры — без изменений исходников

**Запрос:** только исследовать файлы, зависимости, точки входа, запуск и тестирование.

**Действия:** прочитаны README и три исходных скрипта; код не менялся. Итог оформлен в [01_structure.md](01_structure.md).

**Результат:** плоская структура, NumPy/SciPy/Matplotlib, три самостоятельных GUI-скрипта, автоматических тестов нет. Команды запуска в оригинальном README не соответствовали фактическим именам файлов.

## Шаг 3. Аудит научной корректности

**Запрос:** проверить предположения, единицы, формулы, модели, обработку данных и методические ошибки; документировать подробно.

**Действия:** прочитаны все три исходных файла; выражения задачи двух тел и орбитальных переходов сверены с материалами OpenStax, TU Delft и NASA NTRS (ссылки в [02_audit.md](02_audit.md)). Исходный код не редактировался.

**Результат:** основные формулы переходов согласуются с идеальными предположениями. Замечания о площадной скорости, отсутствующем вычислении третьего закона Кеплера, неописанной системе единиц `G=1`, приближённых импульсах и других ограничениях записаны в [02_audit.md](02_audit.md).

**Ограничения проверки:** аудит статический; GUI и тесты не запускались и не добавлялись; численная сходимость исполнением не проверялась.

## Шаг 4. Документация и GitHub-репозиторий

Сначала агент ошибочно завёл отдельную локальную копию журнала. Пользователь уточнил, что нужно работать в исходном клоне и вести материалы в одном репозитории. Отчёты перенесены в проект; исходный README сохранён как `README-upstream.md`, корневой README стал обзором задания.

Пользователь предоставил публичный пустой репозиторий [st115592/ML_task_zero](https://github.com/st115592/ML_task_zero) и запросил `AGENTS.md` с ограничениями по образцу. Подключение и права записи проверены. Правила созданы; исходники и материалы задания размещаются в этом репозитории.
